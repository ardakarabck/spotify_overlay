Spotify Now Playing — Setup

One-time connection. Do this in a normal browser, not inside OBS.

  1. Go to developer.spotify.com/dashboard → Create app.
  2. Set the Redirect URI to the exact address below, then Save.
  3. Copy your app's Client ID and paste it here.

Your Client ID and login token are stored only in this browser (localStorage). Nothing is sent anywhere except Spotify.
